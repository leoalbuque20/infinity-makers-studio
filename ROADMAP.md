# Roadmap — Infinity Makers Studio

## ✅ Concluído

### Sprint 1 — Estrutura base
- [x] Estrutura de pastas e arquivos do projeto
- [x] App desktop com PowerShell/Windows Forms (v0.1 inicial)
- [x] Gerador de arquivos OpenSCAD para placa, chaveiro e luminária
- [x] Exportação STL via OpenSCAD CLI

### Sprint 2 — Reescrita Python + melhorias
- [x] Reescrita completa em Python com CustomTkinter (dark mode)
- [x] Interface com duas colunas e log de saída em tempo real
- [x] Spinners com botões +/− para todas as medidas
- [x] Cantos arredondados nas placas e chaveiros
- [x] Borda em relevo para placas
- [x] Posição do furo configurável (superior/inferior/esquerdo/direito)
- [x] Opção de dois furos simétricos para placas grandes
- [x] Margem e raio do furo configuráveis
- [x] Argola do chaveiro com raio ajustável
- [x] Luminária em três formatos (cilíndrica, hexagonal, quadrada)
- [x] Indicador de OpenSCAD instalado/ausente
- [x] Script `build_windows.bat` para gerar `.exe`

## 🔜 Próximas sprints
